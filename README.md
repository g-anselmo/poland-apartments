# Apartment prices in Poland (Aug 2023 to Jun 2024)

[Versão em português](README.pt.md)

## About
A pipeline that takes monthly CSVs of apartment sale listings in Poland, cleans them with Python (pandas), loads them into PostgreSQL via Docker and answers price questions with SQL.

What it does:
- Merges 11 monthly files (`apartments_pl_*.csv`) and tags each row with its source month.
- Drops the `condition` column and duplicates by `id`, keeping the listing from the latest month.
- Computes `price_per_m2` and flags as outliers anything above 2x or below 0.5x its own city's median.
- Writes `data/clean/apartments_clean.csv` (92,967 rows, 32 columns).
- Docker starts Postgres 16, creates the table, loads the CSV and creates the views automatically.

Data: [Apartment Prices in Poland](https://www.kaggle.com/datasets/krzysztofjamroz/apartment-prices-in-poland) (Kaggle, by krzysztofjamroz), monthly snapshots of sale listings. The raw CSVs are not in this repo: download them and put them in `data/raw/`.

Tools: Python (pandas, NumPy), PostgreSQL 16, Docker Compose.

## Structure
```
data/raw/     original CSVs (one per month)
data/clean/   cleaned CSV generated by the script
Python/       clean_apartments.py, gus.ipynb (salary data) and exploration notebooks
sql/          01_create_tables.sql, 02_load_data.sql, 03_views.sql
docker-compose.yml
```

## How to run
1. Install dependencies: `pip install pandas numpy`
2. Generate the clean CSV, from inside the `Python` folder:
   ```
   cd Python
   python clean_apartments.py
   ```
3. From the project root, start the database (Docker Desktop running):
   ```
   docker compose up -d
   docker compose logs
   ```
   The log should show `COPY 92967` and three `CREATE VIEW` lines, with no `ERROR`.
4. Connect to Postgres (pgAdmin or psql): host `localhost`, port `5434`, database `poland_apartments`, user `postgres`, password from `docker-compose.yml`.

To rebuild the database from scratch: `docker compose down -v`, then `docker compose up -d`. The scripts in `sql/` only run when the volume is empty.

## Views
- `v_median_price_by_city`: median price per m² for each city, outliers excluded.
- `v_warsaw_price_evolution`: monthly median price per m² in Warsaw.
- `v_var_median`: the same series with the previous month (`LAG`) and the month-over-month percentage change.

## Results
- Median price per m² (no outliers): Warsaw 16,779, Kraków 15,000, Gdańsk 13,184.
- In Warsaw the median went from 14,465 in Aug 2023 to 17,917 in Jun 2024, up 23.9%.
- Monthly change ranged from 0.86% to 4.43%, with the biggest jumps in Dec 2023 and Jan 2024.

## Price vs. salary
`Python/gus.ipynb` downloads average monthly gross salaries by powiat from the GUS Local Data Bank API (BDL, variable 64428, 380 powiats, 4 pages of 100), keeps the 15 cities that appear in the apartment data and joins them with the median price per m².

`months_per_m2` = median price per m² / 2024 salary.

| City | Median price per m² (PLN) | Salary 2024 (PLN) | Months of salary per m² |
|---|---|---|---|
| Warsaw | 16,779 | 10,715 | 1.57 |
| Kraków | 15,000 | 10,455 | 1.43 |
| Wrocław | 12,392 | 9,425 | 1.31 |
| ... | | | |
| Katowice | 7,929 | 10,052 | 0.79 |
| Radom | 6,324 | 8,269 | 0.76 |

1 m² costs between 0.76 (Radom) and 1.57 (Warsaw) monthly gross salaries. Katowice has one of the highest salaries and one of the cheapest m², so it ends up near the bottom.

## Limitations
- Prices come from listings, not closed sales.
- The series covers only 11 months, so trend and seasonality can't be separated.
- GUS salaries are yearly averages and the 2024 value is used for the whole price period (Aug 2023 to Jun 2024).
- The rent files (`apartments_rent_*`) are in `data/raw/` but aren't part of the pipeline yet.
